# Concepts

Protocols say how machines talk. These pages cover who is **allowed** to talk, and over which path.

- [Firewalls]({{< relref "firewalls" >}}): rules that allow or drop traffic by address, port and connection state. Cloud security groups are firewalls too.
- [VPN]({{< relref "vpn" >}}): an encrypted tunnel that puts a remote laptop or a whole office on a private network, for example to reach a database that has no public IP.
